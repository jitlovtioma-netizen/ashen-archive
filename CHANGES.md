# Что изменилось (v5.7.1 — Кнопка «⇩ АРХИВ»: seed.zip из Мастерской, фантом побеждён)

## Главное в v5.7.1

1. **Кнопка «⇩ АРХИВ · N КБ» в Мастерской.** Весь проект одним файлом
   (исходники + база + доки + worklog) теперь скачивается прямо из
   браузера — без ssh и ручных команд. Кнопка живёт в тулбаре рядом с
   «⇩ БЭКАП» / «⇧ ВОССТАНОВИТЬ», показывает живой размер архива и
   подсвечена янтарём.
2. **Фантом seed.zip найден и обезврежен.** Архив из public/ исчезал
   уже 5+ раз за историю проекта — каждая пересборка могла «провалиться»:
   dev-вотчер Next.js (Turbopack) в течение секунды после rm+create
   переставал «видеть» файл (зарегистрировано и в public/, и вне его).
   Лечение тройное:
   - архив переехал в **`seed-archive/`** у корня проекта (вне зоны
     ответственности статик-вотчера; в git не входит — .gitignore);
   - раздача через **`/api/seed?t=<токен>`** — подписанная HMAC-ом
     ссылка, только для админов, живёт 15 минут (архив содержит базу
     с паролями — анонимно не раздаётся);
   - пересборка (POST `/api/admin/make-seed`) делает до 3 попыток и
     проверяет результат ДВУМЯ способами — прямым fs и через дочерний
     процесс, что обходит гонку состояния fs в dev-рантайме.
3. **Автовосстановление архива.** `scripts/ensure-seed.mjs` встроен в
   цепочку `bun run dev`: если при старте дев-сервера архива нет — он
   пересобирается автоматически (включая подъём сторожем devkeeper после
   зачистки процессов песочницы). Скрипт никогда не роняет старт dev.
4. **Кнопка «⟳ СОБРАТЬ АРХИВ».** Если архив всё же потерялся — кнопка
   в Мастерской сама предложит пересобрать его прямо из браузера
   (пульсирует янтарём, пока файла нет), после сборки показывает тост
   «АРХИВ СОБРАН» и возвращается в состояние «⇩».
5. **Статус архива — тоже API.** GET `/api/admin/make-seed?requester=X`
   отдаёт { exists, size } (только админам), с той же защитой от
   устаревшего fs-состояния через дочерний stat.
6. **Справка Мастерской** дополнена строкой «⇩ Архив проекта».

→ Для прода ничего не нужно: seed.zip на Vercel не существует
  (gitignored), `/api/seed` там честно ответит «архив потерян».
  Схема БД не менялась — db:push/db:seed не требуются.

# Что изменилось (v5.7 — Ирис не отпускает: стадии 5–6, эхо карточек, «ирис в цифрах»)

## Главное в v5.7

1. **Стадии 5–6: «ИРИС НЕ ОТПУСКАЕТ».** Поглощение вышло за прежний
   предел: 6-е и 7-е открытия доводят растворение до ~68% и ~78%
   чистых слов. Прибор в досье переименован («ИРИС НЕ ОТПУСКАЕТ»),
   счётчик уходит в «∞», рамка модалки дышит чаще и глубже
   (двойное кольцо + ирис-виньетка, отдельная анимация irisDevourRing).
2. **Заголовок досье растворяется.** На стадиях 5+ даже ИМЯ записи
   тонет в ирисе: вместо зелёного свечения — переливающийся градиент
   (irisTitleFlow), на 6-й стадии добавляется «дыхание» расфокусировки
   (irisNameBreathe: буквы почти не держат форму). Досье перестаёт
   «глючить» — оно тает.
3. **Ирис-эхо на карточках.** Наведение на ирис-досье в списке — и оно
   отвечает из-под страницы: 10 тихих фраз вполголоса («открой меня»,
   «здесь было больше слов», «ирис ждал»…), мельче и прозрачнее
   обычного шёпота, средняя полоса экрана. Анти-шквал 2.5с; тач-
   устройства молчат (у них нет наведения); приветствие и прощание
   больше не глотаются эхом (троттлинг теперь только для него).
4. **Превью карточки худеет вместе с досье.** Ирис ест не только текст
   в модалке — превью в списке тоже растворяется по стадии (статично,
   без мерцания). Карточка «ꙮ ПОГЛОЩЕНИЕ N/5» → «ꙮ РАСТВОРЕНО» →
   «ꙮ ИРИС НЕ ОТПУСКАЕТ» (чип течёт быстрее, на 6-й стадии дышит).
5. **Встреча стадии 5+: ирис не здоровается.** Открытие поглощённого
   досье на высоких стадиях встречает не приветствием, а констатацией:
   8 жёстких фраз («ты опять здесь», «тебя осталось мало», «дальше
   читает ирис»…), крупнее и холоднее тоном.
6. **Достижение «ꙮ Он Не Отпускает» (IRIS_BOUND, оба мира).**
   Восьмое открытие поглощённого досье: «ирис дочитывает его за
   тебя — ты просто держишь страницу».
7. **«Ирис в цифрах» в Мастерской.** Новый блок в сводке архива:
   агрегация поглощения по ВСЕМ стражам обоих миров — сколько
   ирис-досье в архиве, скольких стражей коснулся ирис, сколько
   открытий суммарно и сколько слов съедено (счётчик переливается
   ирисом). Топ-8 досье: открытия ✕, читатели 👤, мини-шкала стадии
   самого преданного читателя, оценка съеденных слов. Читает только
   Progress — ничего не пишет.

# Что изменилось (v5.6 — Ирис поглощает: досье тает с каждым открытием)

## Главное в v5.6

1. **«Ирис поглощает» — жуткая механика деградации досье.** Каждое
   повторное открытие ирис-досье (записи с ⟪…⟫) кормит ирис: первое
   чтение бесплатно, но со второго чистые слова текста начинают
   растворяться в переливающихся глифах — ЗА пределами помеченных
   фрагментов. Стадии 0..4: «ирис только смотрит» → «ирис тянется к
   словам» → «ирис забирает фразы» → «половина досье — уже ирис» →
   «досье почти растворено» (до ~55% чистых слов проглочено).
   Счётчик открытий хранится в прогрессе (новое поле irisOpens —
   карта «id досье → сколько раз открыт»).
2. **Прибор «ПОГЛОЩЕНИЕ» в досье.** Над описанием ирис-досье —
   метаприбор архива: глиф ꙮ, пять наливающихся ирис-градиентом
   сегментов, счётчик N/5 и подсказка стадии. На высоких стадиях
   прибор тревожнее (розовая рамка), а сама модалка досье получает
   внутреннюю переливающуюся кайму (::after-кольцо — не конфликтует
   с анимацией входа).
3. **Чип на карточке.** В списках (лор, герои, локации) ирис-досье
   со второго открытия помечено чипом «ꙮ ПОГЛОЩЕНИЕ N/5», с пятого —
   «ꙮ РАСТВОРЕНО» (переливающаяся рамка угрозы).
4. **Прощальный ирис-шёпот.** При ЗАКРЫТИИ ирис-досье ирис
   прощается: 12 новых фраз («ты вернёшься», «ирис сохранил твой
   взгляд», «до встречи в цветах»…), всплывают в нижней половине
   экрана — ирис «уходит вниз» вслед за захлопывающейся модалкой.
5. **Достижение «ꙮ Глазами Ириса» (IRIS_DEVOTED, оба мира).**
   Открыть одно ирис-досье пять раз — «пока было что открывать».
   Награда за упорство в потере: каждое возвращение кормило ирис.
6. **Тост прогресса коллекции.** При новом прочитанном ирис-досье
   (если в мире их больше одного) — тост «ИРИС ПРОЧИТАН X ИЗ Y».
7. **Мини-бар в Профиле.** Статистика «ИРИС ПРОЧИТАН» получила
   градиентный мини-бар (течение ириса, как у глифов досье).

4. **Первые ирис-досье в архиве.** В лор добавлены две записи с

   места, где цвет отходит от материи). Ирис рассказывает о себе
   сам; коллекционная ачивка достижима с первого дня.

# Что изменилось (v5.4 — Полное искажение ⟪…⟫, шёпот Созидателя)

## Главное в v5.4

1. **⟪ ПОЛНОЕ ИСКАЖЕНИЕ ⟫ — ирис вместо свечения.** В Мастерской (и в
   правке досье владельцем) рядом с «⟦ ПОМЕТИТЬ ПОРЧЕЙ ⟧» появилась
   вторая кнопка. Выделите текст и нажмите — фрагмент растворится
   БЕЗВОЗВРАТНО: вместо слов переливающиеся глифы (бирюза→аметист→
   роза→золото, как плёнка нефти на воде). Порча СВЕТИТСЯ красным и
   иногда показывает призрак слова; полное искажение НЕ СВЕТИТСЯ, а
   ПЕРЕЛИВАЕТСЯ — и никогда не раскрывает исходный текст. Даже хвостовая
   пунктуация растворяется: от фразы остаётся только ритм пробелов.
   Свой набор глифов (ꙮ ◐ ☾ ✶ ⨀…), живой дрейф каждые ~0.6с, при
   наведении ирис уплотняется и течёт быстрее.
2. **Счётчики и генеральная уборка.** Под кнопками — «// порча: N ·
   ирис: N //». «✕ СНЯТЬ ВСЕ МЕТКИ» (бывш. «СНЯТЬ ВСЮ ПОРЧУ») убирает
   ОБЕ разновидности меток. Живой предпросмотр показывает смешанные
   фрагменты так, как их увидят стражи; если в тексте только ирис —
   внизу подпись «СМЫСЛ УТРАЧЕН БЕЗВОЗВРАТНО».
3. **Шёпот Созидателя (взгляд ≥ 80%).** Когда взгляд почти полон, архив
   перестаёт молчать: по краям экрана изредка всплывают плашки-фразы —
   «он наблюдает», «вы в его ловушке», «КЛЮЧ», «не оборачивайся»,
   «он видит сквозь экран»… 31 фраза, три стиля (переливающаяся ирисом
   строка / чип с рамкой и срезанными углами / строка с руной-глазом ꙮ).
   При 90%+ шёпот настойчивее: чаще и крупнее. Плашки — чистая
   атмосфера: pointer-events none, aria-hidden, под reduced-motion —
   полная тишина.
4. **Рендер везде.** Полное искажение работает в досье (RecordModal),
   карточках (RecordCard) и превью редактора; «призраки смысла»
   показываются ТОЛЬКО у порчи — ирис не возвращает долгов. Скринридеры
   по-прежнему читают исходные слова (sr-only).
5. **Доступность.** prefers-reduced-motion: ирис замирает статичным
   градиентом, шёпоты не оживают вовсе, дрейф/blur отключаются.

# Что изменилось (v5.3 — Порядок записей drag-n-drop, черновики форм, sticky-панель)

## Главное в v5.3

1. **⠿ Порядок записей — архив в вашей власти.** В Мастерской строки
   списка перетаскиваются за ручку ⠿: новый порядок увидят ВСЕ стражи —
   список героев, лора, локаций и фракций следует воле Созидателя, а не
   алфавиту. Работает в обоих мирах и во всех вкладках, кроме загадок и
   достижений. При активном поиске или фильтре перетаскивание выключается
   (ручка становится «слепой» + подсказка в тулбаре) — порядок подмножества
   неоднозначен. Красивый «призрак» записи с янтарным свечением следует за
   курсором, строка-источник гаснет пунктиром.
2. **Порядок бессмертен.** merge-seed больше не трогает sortOrder ни у
   каких записей (это презентационное поле — сид не сбрасывает порядок,
   проверено: кастомный порядок фракций пережил пересев). Бэкап и
   восстановление переносят порядок автоматически (поле в дампе).
   Новая запись с sortOrder 0 встаёт наверх списка — «свежее — выше».
3. **⌫ Черновики форм — текст не потеряется.** Правки в редакторе
   Мастерской автосохраняются в браузере (localStorage, дебаунс 400 мс).
   Перезагрузка вкладки, случайное закрытие, крах сборки — не страшны:
   при повторном открытии записи черновик восстановится с тостом
   «ЧЕРНОВИК ВОССТАНОВЛЕН». Кнопка «⌫ СБРОС» откатывает к сохранённой
   версии; успешное сохранение и удаление записи чистят черновик.
4. **● ИЗМЕНЕНО + защита вкладки.** Пульсирующий индикатор в панели
   действий показывает несохранённые правки; вкладка с правками при
   закрытии просит подтверждение (beforeunload).
5. **Sticky-панель действий.** СОХРАНИТЬ / ОТМЕНА / ⌫ СБРОС прилипают к
   низу экрана при прокрутке длинной формы (blur-фон, янтарная подсветка
   при правках) — больше не нужно скроллить 20 полей вниз ради кнопки.

# Что изменилось (v5.0 — Мастерская бессмертна: порча по выделению, цвета досье, загадки и достижения)

## Главное в v5.0

1. **Правки Мастерской больше НЕ сбрасываются.** Seed полностью переписан на
   MERGE-режим: заливка новой версии архива НИЧЕГО не удаляет. Всё, что ты
   создал или отредактировал в Мастерской (или владелец — в своём досье),
   помечается флагом `userModified` и seed обходит такие записи стороной.
   Пользователи, их роли, привязки к персонажам и прогресс — неприкосновенны.
   Тексты новых версий доставляются только в записи, которые ты не трогал.
   Записи, убранные из сида, остаются в базе (сжечь их можно в Мастерской).
2. **Порча по выделению.** В редакторе описания (Мастерская ИЛИ режим правки
   досье) выдели мышкой любой фрагмент текста и нажми «⟦ ПОМЕТИТЬ ПОРЧЕЙ ⟧» —
   нечитаемым и искажённым станет ИМЕННО он, остальной текст останется чистым.
   Повторное нажатие на помеченном выделении снимает порчу; «✕ СНЯТЬ ВСЮ
   ПОРЧУ» убирает все метки. Под полем — живой предпросмотр «как увидят
   стражи». Метки хранятся прямо в тексте (⟦ … ⟧), работают в любом досье.
3. **Цвет досье — как фиолетовое у Кали, но любой.** В Мастерской у героев,
   второстепенных и локаций появилось поле «◆ ЦВЕТ ДОСЬЕ»: фиолетовое
   (проклятое), синее (глубинное), зелёное (ядовитое), янтарное
   (жертвенное), багровое (кровавое), голубое (ледяное), розовое (фантомное).
   Меняется фон модалки, рамка, свечение заголовка, сканирующие линии — и
   ЦВЕТ ПОРЧИ под стать теме. Кали и «Отражение» остаются фиолетовыми по
   наследию. В списках у цветных досье — чип «◆».
4. **Загадки — в Мастерской.** Новый таб «🎯 ЗАГАДКИ»: создавай загадки-врата
   к любой записи по имени (герой, лор, локация). Поля: имя записи, заголовок
   и подзаголовок врат, текст (строка = строка в вратах), верные ответы через
   запятую, подсказка, мир (Элария/Голарион/любой). Ответы проверяются НА
   СЕРВЕРЕ — игроки не смогут подсмотреть их в коде страницы. Все 13 старых
   вшитых загадок переехали в базу (вшитые остались страховкой, если база
   пуста). Прогресс разгаданных не сброшен.
5. **Достижения — в Мастерской.** Новый таб «🏆 ДОСТИЖЕНИЯ»: код (латиница,
   напр. FIRST_SHARD), название, описание, сигила, мир. Новые достижения
   автоматически появляются в реестре профиля стражей.
6. **Летописи удалены ПОЛНОСТЬЮ** — из Мастерской, API, схемы БД и сида.
   Таблица Chronicle будет удалена при `db:push` (это ожидаемо).
7. **Аудит длины текстов.** Проверены все 131 запись архива. Читаемые
   длинномеры сокращены без потери фактов: Каэль Валькрейн (1780→~1200),
   Странник (1743→~1000), Меч Кайма (1588→~1000), Тифлия (1341→~950).
   «Длинные» числа у расплавленных zalgo-записей (Кали, Мартин МакДона,
   секреты) — это диакритики порчи, а не читаемый текст: их не трогали.
   В Мастерской счётчик описания теперь предупреждает «· длинновато» после
   1500 символов.
8. **Мягкая рекомендация объёма** — архив советует держать досье до 1500
   символов (жёлтая подсветка счётчика), жёсткий потолок остался 6000.

    bun run build
    bun run start:next

(архив v4.3.3 или старее; в v4.3.4 исправлено автоматически)

ПРИЧИНА: в prisma\schema.prisma в блоке datasource db стоит
`provider = "sqlite"`, а DATABASE_URL — postgres (Supabase). Prisma
пытается открыть postgres-ссылку как sqlite-файл. Авто-синк из v4.3.3
должен был переключить провайдер сам, но его регулярка первым делом
цеплялась за строку-КОММЕНТАРИЙ в шапке схемы (там был текст
`// postgresql://… → provider = "postgresql"`) — «переключал» комментарий,
а настоящий провайдер оставался sqlite.

ФИКС (1 правка + 3 команды):
  1. Открой prisma\schema.prisma, найди блок:
       datasource db {
         provider = "sqlite"     ← замени ТОЛЬКО эту строку
         url      = env("DATABASE_URL")
       }
     Постав provider = "postgresql" (строки с // — не трогай).
  2. bun run db:generate
  3. bun run db:push
  4. bun run db:seed

locations 13 · chronicles 6 · achievements 6.

- Ложные паттерны убраны из комментариев обеих схем.
